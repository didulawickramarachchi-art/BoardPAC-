# BoardPAC

BoardPAC is a cross-platform board management application built with Flutter. It provides secure, role-based tools for administrators, board secretaries, and board members to manage meetings, agendas, papers, approvals, and organizational resources.

## Features

- Secure login with two-factor authentication
- Role-based access control
- Meeting and participant management
- Agenda and agenda-item management
- Board papers and attachments
- PDF viewing and annotations
- Comments, reactions, and document sharing
- Paper approval workflows
- Favorites and member document library
- Meeting reminders and local notifications
- News and announcements
- Global search
- User, device, and privilege management
- Audit logs and administrative reports
- Light and dark themes
- Responsive layouts
- Offline paper storage

## Technology Stack

- Flutter and Dart
- Riverpod for state management
- Dio for API communication
- Flutter Secure Storage for sensitive data
- Syncfusion PDF Viewer
- Local notifications with timezone support

## Supported Platforms

- Android
- iOS
- Web
- Windows
- macOS
- Linux

## Prerequisites

Before running the project, install:

- Flutter SDK with Dart 3.11.4 or later
- Android Studio or Visual Studio Code
- Android SDK for Android development
- Xcode for iOS and macOS development
- A running BoardPAC backend API
